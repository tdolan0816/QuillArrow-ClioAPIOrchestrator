# Changelog — 2026-10-27

## Mobile layout and Progressive Web App

Phone / small-tablet rendering for the existing React app, plus an installable PWA shell. Desktop rendering (≥1024px) is unchanged: every responsive class is gated behind a Tailwind breakpoint that resolves to the original class at `lg`, and the PWA additions are new files or additive tags only.

Decision recorded in `docs/08_Operations/Mobile_Support.md`: responsive + PWA instead of a React Native / Flutter rebuild.

### Frontend — layout

- `frontend/src/components/Layout.jsx`
  - Sidebar becomes an off-canvas drawer below `lg`: `fixed inset-y-0 left-0 z-40 ... -translate-x-full`, slides in with `translate-x-0`, backdrop `fixed inset-0 z-30 bg-black/50 lg:hidden`. At `lg`: `lg:static lg:translate-x-0 lg:transition-none` (original in-flow 256px sidebar).
  - Hamburger button (`lg:hidden`) in the header opens the drawer; an X button in the drawer brand row closes it. Drawer also closes on Escape, backdrop tap, or tapping a nav link.
  - Header search box `hidden lg:block`. User full name and "Logout" label `hidden sm:inline` (role pill and logout icon remain). Header padding `px-4 lg:px-6`, right-side gap `gap-3 lg:gap-4`.
  - Main content padding `p-4 lg:p-6`. Content column gets `min-w-0`.
  - Root uses `.app-shell` instead of `h-screen`.
  - Nav `<nav>` gets `overflow-y-auto` for short phone screens.
- `frontend/src/index.css` — new `.app-shell { height: 100vh; height: 100dvh; }`. Desktop = 100vh (same as before). Mobile uses the dynamic viewport.
