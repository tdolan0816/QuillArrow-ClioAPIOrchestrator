# Release notes template

Copy to `YYYY-MM-DD.md` (or `X.Y.Z.md`) after a successful Azure deploy. Keep [[Unreleased]] empty except work not yet in production.

```
# Release …

YYYY-MM-DD

## Added
-

## Changed
-

## Fixed
-
```

Same bullets can be pasted into the VS Code App Service deploy comment. Git: `.gitmessage` at repo root; in VS Code set `git.commitTemplate` to that file if you want the editor to open it.
